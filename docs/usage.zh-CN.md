# 使用指南

## 五笔输入

输入五笔 86 编码（a-z）。每页最多显示 5 个候选词，按频率排序并支持前缀匹配。候选词显示剩余编码字母作为提示（如 `3.式aa` 表示完整编码为 `aa` 加所示后缀）。

| 按键 | 操作 |
|---|---|
| `a`-`z` | 向五笔编码追加字母 |
| `1`-`5` | 按编号选择候选词 |
| `Space` | 上屏第一个候选词 |
| `Enter` | 将原始编码作为文本上屏 |
| `Esc` | 取消并清空编码输入 |
| `Backspace` | 删除最后一个编码字母 |
| `=` / `-` | 下一页 / 上一页候选词 |
| `` ` `` | 切换生僻字模式（输入过程中） |
| `z` | 重复上屏上一个五笔字（空闲时） |

当 4 字编码对应唯一候选词时，自动上屏。

## 临时拼音模式

按下 `]`（右方括号）进入临时拼音模式。输入拼音（不需要声调）来查找字符/词组。每个候选词旁显示其五笔编码（如 `1.中 [khk]`）。选择候选词后自动退出回五笔输入模式。

| 按键 | 操作 |
|---|---|
| `]` | 进入临时拼音模式 |
| `a`-`z` | 向拼音输入追加字母 |
| `1`-`5` | 选择候选词并退出 |
| `Space` | 上屏第一个候选词并退出 |
| `Enter` | 将原始拼音作为文本上屏并退出 |
| `Esc` | 取消并退出 |
| `=` / `-` | 下一页 / 上一页候选词 |

## 临时文本模式

按下 `[`（左方括号）进入临时文本模式。所有输入原样收集（不做五笔解析）。按 `Enter` 上屏文本（前导 `[` 会被去除）。

| 按键 | 操作 |
|---|---|
| `[` | 进入临时文本模式 |
| 可打印字符 | 追加到缓冲区 |
| `Space` | 向缓冲区追加空格 |
| `Enter` | 上屏文本（不含前导 `[`） |
| `Esc` | 取消 |

## 斜杠模式

按下 `/` 进入斜杠模式。输入简短英文字符串；按 `Space` 或 `Enter` 上屏。前导 `/` 会包含在输出中。适合在不切换到英文模式的情况下输入命令或路径。

| 按键 | 操作 |
|---|---|
| `/` | 进入斜杠模式 |
| 可打印字符 | 追加到缓冲区 |
| `Space` | 上屏整个缓冲区（包含 `/`） |
| `Enter` | 上屏整个缓冲区（包含 `/`） |
| `Backspace` | 删除最后一个字符（仅剩 `/` 时取消） |
| `Esc` | 取消 |

示例：`/` + `Space` → `/` · `/rewind` + `Space` → `/rewind`

## 中英文切换

按下 **右 Ctrl** 在中文和英文模式之间切换。英文模式下，Fcitx5 任务栏图标显示 "En"。在英文模式下，所有按键正常透传。

## 中文标点

在中文模式下，以下标点按键自动转换为中文标点：

| 按键 | 输出 | 按键 | 输出 |
|---|---|---|---|
| `,` | ， | `.` | 。 |
| `!` | ！ | `?` | ？ |
| `;` | ； | `:` | ： |
| `^` | …… | `\` | 、 |
| `<` | 《 | `>` | 》 |
| `_` | —— | | |

双引号（`"`）和单引号（`'`）自动生成中文智能引号
（`"\`"` 和 `'`'`），在开引号和闭引号之间交替。
